# Моя Ферма — Telegram Mini App v4 Animals Update

Обновление под публичный тест: главный экран и игровые разделы в фермерском casual-стиле, плюс новые реалистичные первые уровни загонов для крупных животных.

## Что внутри

- `index.html` — точка входа Telegram Mini App.
- `styles.css` — адаптивная 9:16 верстка, модальные окна, кнопки, кликабельные зоны.
- `app.js` — игровая логика, сохранение прогресса, Telegram SDK.
- `assets/` — готовые игровые экраны WebP.

## Экраны

- Главная ферма.
- Курятник.
- Свинарник — первый уровень: 1 свинья в отдельном просторном загоне, а не куриная ячейка.
- Овчарня — первый уровень: открытый загон/пастбищный формат для 1 овцы.
- Коровник — первый уровень: крупное стойло для 1 коровы.
- Поля.
- Рынок.
- Заказы.
- Исследования.

## Механика животных

- Куры: 4 → 8 → 12 → 16 мест.
- Свиньи: 1 → 2 → 4 → 6 мест.
- Овцы: 1 → 3 → 5 → 8 мест.
- Коровы: 1 → 2 → 3 → 4 места.

В этой версии добавлены первые уровни крупных загонов, покупка животных, улучшения и сбор продукции.

## Telegram Mini App

Включено:

```js
Telegram.WebApp.ready();
Telegram.WebApp.expand();
Telegram.WebApp.disableVerticalSwipes();
```

## Публикация

Залить содержимое архива на HTTPS-хостинг, после этого указать URL в BotFather для Web App / Menu Button.
