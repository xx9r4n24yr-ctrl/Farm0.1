# Моя Ферма — Telegram Mini App v7

Многофайловая сборка, как нужно для GitHub Pages:

- `index.html`
- `styles.css`
- `app.js`
- `assets/` с картинками экранов

## Как залить на GitHub Pages

Загружай **содержимое архива в корень репозитория**, чтобы структура была такая:

```
index.html
styles.css
app.js
assets/home.jpg
assets/coop1.jpg
...
```

Не загружай папку `telegram_farm_miniapp_v7_multifile` целиком внутрь репозитория, иначе GitHub Pages откроет не тот путь.
